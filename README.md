# Primeiro-projeto
# Você consegue cadastrar clientes e criar contas, fazer depósitos, realizar saques e consultar o extrato com as informações do titular e o valor disponível.
# O projeto é dividido em três partes principais. A classe Cliente guarda o nome e o CPF da pessoa, a classe ContaBancaria cuida do dinheiro, e a classe Banco organiza e guarda a lista com todas as contas criadas.
